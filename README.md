# BC Agentic Hub — releases

Signed and notarized builds of **BC Agentic Hub**, a native macOS app that manages Claude Code skills, agents, hooks, MCP servers and plugins, globally and per project.

**Download:** grab the `.dmg` from the [latest release](https://github.com/nemesis312/bc-agentic-hub-releases/releases/latest). Each release also has a `.sha256` file.

- macOS 14 or later, Apple Silicon and Intel.
- Free.
- The app updates itself from this repo.

Website: https://agentichub.boricuacoder.dev · Made by [BoricuaCoder](https://boricuacoder.dev).

This repo only hosts release builds; the source code is not published here.

## Reporting issues

Found a bug or have an idea? [Open an issue](https://github.com/nemesis312/bc-agentic-hub-releases/issues/new/choose).

Search the [existing issues](https://github.com/nemesis312/bc-agentic-hub-releases/issues) first in case it's already reported. For a bug, include the app version (About window), your macOS version and the steps to reproduce it. Reports in English or Spanish are welcome.
